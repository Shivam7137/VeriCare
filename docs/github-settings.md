## Branch protection limitation

Visibility was preserved and no subscription change was made. **main is unprotected.** CI runs on pushes and pull requests but is not an enforced merge gate. CODEOWNERS and the contribution guide provide review guidance without enforcing approvals.

When protection is available, require the `verify` status check on an up-to-date branch, one approval, code-owner review, dismissal of stale approvals, resolved conversations, and no force pushes or branch deletion. Decide administrator bypass and the actual reviewer roster with the team.

No collaborators were invited because teammate GitHub identities were not supplied. No deployment, paid provider, secret, or open-source license was configured.
