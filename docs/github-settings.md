# GitHub configuration

[Shivam7137/patient-request-coordination](https://github.com/Shivam7137/patient-request-coordination) is a private, disposable collaboration workspace with main as its default branch.

- Direct pushes are allowed. Branches and pull requests are optional.
- No CI workflows, required checks, branch protection or required reviews.
- No CODEOWNERS, mandatory issue forms or pull request template.
- GitHub Actions is disabled for now. Dependabot version updates are removed, and the setup-generated dependency pull requests are closed.
- Merge commits, squash merging and rebase merging are all available. Feature branches are not automatically deleted.
- Eight package issues and one demonstration milestone remain as optional planning aids.
- Dependency vulnerability alerts remain enabled; they do not block pushes or create a review gate.

Local test, build and formatting commands are still available on demand. No collaborators were invited because teammate GitHub identities were not supplied. Hosting and live integrations are not configured.
