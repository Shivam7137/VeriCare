# Contributing

This is a disposable collaboration workspace. Push directly to main, or use a branch and pull request if that helps coordinate overlapping work. No required reviews, CI checks, issue assignments or handoff forms.

Use `npm run check`, `npm run test:integration` and `npm run format` when useful. They are optional local tools. Keep package-lock.json with dependency changes and use npm ci for installation.

Keep shared record shapes in packages/contracts and let others know about interface changes that affect their work. The eight package issues are a starting checklist, not an approval process.

Use fictional records and keep credentials out of Git. Preserve other people's changes and data. Briefly note what works and what is unfinished so teammates can pick it up.
